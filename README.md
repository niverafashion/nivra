# Nivra Store

Simple women fashion online store.

## How to edit products
Open `index.html`

Find:
```html
<div class="product-card">
```

Change:
- image
- product name
- price

## Images
Put your images inside:
`images/`

Example:
- product1.jpg
- product2.jpg
- hero.jpg

## GitHub Pages
Upload all files to GitHub repository and enable GitHub Pages.
